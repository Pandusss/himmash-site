清洗是再生塑料回收生产线的关键环节：颗粒质量在很大程度上取决于它。挤出机和熔体过滤器无法弥补进料时没有洗掉的东西：泥沙和有机物会一直到达过滤网，并进入成品。下面介绍清洗线由哪些设备组成、每个环节发生了什么，以及各设备之间如何匹配。

## 塑料清洗线由哪些设备组成

针对污染薄膜、吨袋（FIBC）丝和硬质废料，典型流程如下：

1. **破碎。** 撕碎机或破碎机将原料破碎到工作尺寸。
2. **预清洗。** 浮选清洗机分离泥沙、石块和重质杂质。
3. **二次清洗。** 摩擦清洗机在含清洗剂的热水中通过摩擦清洗原料。
4. **脱水。** 脱水离心机以机械方式去除水分，使残余含水率降至3–5%。
5. **干燥。** 滚筒干燥机或重力立式干燥机去除残余水分。
6. **污水处理。** 废水经处理后回用于循环。

以上为典型流程。清洗设备的组成和顺序根据具体原料确定：在其他生产线中（例如KPTBO-300综合设备），清洗级数和顺序有所不同。下文设备参数均为目录标准型号；在成套设备中，各单元可能采用其他型号，产能和功率有所不同。

破碎尺寸根据清洗设备的能力确定。Himmash的摩擦清洗机和脱水离心机可接受不超过50 mm的薄膜、不超过100 mm的PP丝和不超过30 mm的厚壁塑料。

各设备之间不仅要在碎片尺寸上匹配，还要在产能上匹配：生产线的速度取决于最慢的设备。设备之间通常用螺旋输送机输送原料，干燥后的片料则采用气力输送。

## 浮选清洗机：重污染原料的预清洗

经撕碎机或破碎机处理后，原料进入[塑料浮选清洗机](../../equipment/flotation-machine/)的水槽。带叶片的纵向轴对原料进行强力搅拌，冲洗并击落污物、石块、泥沙和重质异物。比重大于1（即比水重）的颗粒沉入槽底并定期清除。聚乙烯和聚丙烯比水轻，因此浮在水面，继续进入下一工序。对混合原料来说这是额外的好处：较重的聚合物（如PVC和PET）也会随污物一起沉底。

浮选属于粗洗。其任务是去除大部分污物、减轻后续工序负荷，使摩擦清洗机处理的是经过预清洗的原料，而不是泥沙。泥沙具有磨蚀性：如果大量泥沙进入摩擦清洗机，会加速转子叶片和筛网的磨损，并使水更快变脏。Himmash浮选清洗机产能最高500 kg/h，装机功率不超过5 kW，采用变频控制，控制台操作。

## 摩擦清洗机：薄膜和吨袋丝如何清洗

[高速摩擦清洗机](../../equipment/friction-washer/)（转子式）是生产线的主要清洗设备。原料在加热的清洗剂水流下，依靠与高速转子叶片的摩擦进行清洗。机壳为八角形：各棱面打乱物料流，使原料做无规则运动，因此每个碎片都会反复与叶片以及其他碎片摩擦。用过的污水经底部筛网自流排出。

热水和清洗剂可去除机械作用无法去除的污染：油脂污染、标签残胶、有机物。摩擦则将附着的污物从薄膜和丝料表面剥离。清洗剂定量投加，便于控制其用量，以及随后需要从水中去除的表面活性剂量。

清洗机的产能取决于原料种类。薄膜和丝料蓬松，同等重量下在机壳内占用的空间更大，因此其处理量低于硬质料和PET碎片。

| 参数 | 数值 |
|---|---|
| 产能：薄膜、丝料 | 最高500 kg/h |
| 产能：硬质料 | 最高700 kg/h |
| 产能：PET碎片 | 最高900 kg/h |
| 装机功率 | ≤22 kW |
| 碎片尺寸：薄膜 | ≤50 mm |
| 碎片尺寸：PP丝 | ≤100 mm |
| 碎片尺寸：厚壁塑料、PET碎片 | ≤30 mm |

转子高速运转，因此设备寿命取决于转轴的平衡和轴承组件。Himmash制造的[摩擦清洗机转轴和离心机转子](../../equipment/screws-and-shafts/)经过高精度动平衡，叶片衬板采用经热处理的高强度钢，并用不锈钢紧固件固定。

## 脱水离心机：将塑料含水率降至3–5%

清洗后，原料中仍含有大量水分。机械脱水比蒸发更便宜，因此在清洗和干燥之间设置[脱水离心机](../../equipment/centrifuge/)。机内带叶片的转子高速旋转：原料被甩向筛网，水穿过筛网排出，脱水后的物料被送出设备。出料越干，干燥负荷越小，能耗越低。

Himmash脱水离心机可接受含水率不超过17%的薄膜、不超过15%的PP丝和厚壁塑料，并将含水率降至3–5%。设备自动卸料，泥渣由功率1.5 kW的独立螺旋排出。

| 参数 | 数值 |
|---|---|
| 产能 | 最高500 kg/h |
| 残余含水率 | 3–5% |
| 工作轴长度 | 不小于2,000 mm |
| 主轴转速 | 1,500 rpm |
| 装机功率 | 37–55 kW |
| 启动系统 | 两级启动 |
| 重量 | ≤2,500 kg |

## 离心脱水后的干燥：滚筒式还是重力式

干燥机类型根据原料形态选择。厚壁硬质料采用滚筒式干燥机：物料在旋转滚筒中翻动，并由热风吹扫。薄膜和吨袋丝质轻且易缠结，因此采用重力立式干燥机，物料靠自重下行并由热风吹扫。Himmash干燥机参数可按需提供。

干燥并非最后一道防线。挤出机前的储料仓利用气流对原料进行补充干燥，熔体中残留的水分和气体则由挤出机的真空排气抽除。

## 闭路循环水：T-5000 污水处理系统

清洗线持续耗水，并排出含泥沙、悬浮物、油脂、有机物、清洗剂中的表面活性剂和纳米塑料的废水。此类废水排入市政排水管网受到限制：污染物最高允许浓度由俄罗斯《冷水供应与排水规则》（Правила холодного водоснабжения и водоотведения）规定。

[T-5000 系统](../../equipment/water-treatment-t5000/)是闭路循环水系统，可处理废水，使水回用于生产循环最多20次。处理量为3–10 m³/h。处理采用电气浮、电絮凝、电解、电渗析、吸附过滤和机械过滤，分两级进行：一级用于循环用水，一级用于排入排水管网。系统可安装在车间内，也可作为独立集装箱单元；适用环境温度+5至+45 °C，占地35 m²，只需1人操作。除悬浮物和泥沙外，系统还能去除水中的石油类和油脂、有机杂质、金属氢氧化物、纳米塑料和表面活性剂。

| 指标 | 进水 | 出水 |
|---|---|---|
| 悬浮物 | ≤50,000 mg/L | <300 mg/L |
| 油脂、石油类、油类 | ≤5,000 mg/L | <0.1 mg/L |
| 有机杂质 | ≤5,000 mg/L | <300 mg/L |
| 表面活性剂 | ≤3,000 mg/L | <0.5 mg/L |
| 泥沙、重金属氧化物 | ≤10,000 mg/L | 0.1–5.0 mg/L（锌） |
| 纳米塑料 | ≤10,000 mg/L | <100 mg/L |
| COD | ≤20,000 mg/L | 30–150 mg/L |

清洗线应按实际需要处理的最脏原料来选型，而不是按干净样品。各设备在产能和碎片尺寸上应一致：Himmash的浮选清洗机、处理薄膜时的摩擦清洗机以及脱水离心机，产能均为最高500 kg/h，清洗机和离心机的允许碎片尺寸相同。污水处理最好从一开始就与清洗段同步规划：其处理量按整个清洗段的用水量选配。
