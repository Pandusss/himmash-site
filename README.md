# Сайт НПО «Химмаш»

Новый сайт химмаш24.рф на основе утверждённой дизайн-концепции 01. Три языка (русский, английский, китайский), каталог из 14 позиций, сертификаты с переводом, раздел статей для SEO.

Статический сайт на [Astro](https://astro.build): на выходе обычные HTML-файлы, которые можно разместить на любом хостинге, в том числе бесплатно на GitHub Pages.

## Запуск

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev      # локально: http://localhost:4321
npm run build    # готовый сайт в папке dist/
npm run preview  # посмотреть собранный dist/
```

## Структура

| Где | Что |
|---|---|
| `src/i18n/ru.ts`, `en.ts`, `zh.ts` | Все тексты интерфейса и главной страницы. Русский — исходный, у переводов та же структура. |
| `src/data/products.ts` | Список оборудования: адрес страницы, категория, фото, связанные позиции, этапы технологической цепочки. |
| `src/data/products.ru.ts`, `.en.ts`, `.zh.ts` | Тексты, характеристики, цены и условия по каждой позиции. |
| `src/data/documents.ts` | Сертификаты и ТУ: расшифровка и переводы. Сканы — в `public/img/docs/`. |
| `src/data/company.ts` | Телефон, почта, адрес, разметка организации для поисковиков. |
| `src/content/articles/<язык>/<адрес>.md` | Статьи. |
| `src/views/` | Шаблоны страниц. `src/pages/` только связывает адреса с шаблонами. |
| `src/styles/global.css` | Стили утверждённой концепции без изменений; `site.css` — новые блоки. |
| `docs/glossary.md` | Глоссарий терминов для переводов. |

Адреса: русская версия без префикса (`/equipment/centrifuge/`), английская — `/en/…`, китайская — `/zh/…`.

## Как добавить статью

1. Создайте `src/content/articles/ru/<адрес-латиницей>.md`:

   ```markdown
   ---
   title: "Заголовок до 70 символов"
   description: "Описание для поисковиков, 140–170 символов"
   date: 2026-10-15
   cover: "img/products/08-01-1200.webp"
   coverAlt: "Что изображено на фото"
   products: ["friction-washer", "centrifuge"]
   ---

   Текст статьи в Markdown. Разделы — через ##.
   ```

2. Переводы кладите с тем же именем файла в `en/` и `zh/`. Если перевода нет, статья просто не появится в этой версии.
3. Ссылки на оборудование внутри статьи — относительные: `[центрифуга](../../equipment/centrifuge/)`. Они работают во всех языках.
4. Черновик можно скрыть строкой `draft: true`.

## Форма заявки

Пока адрес обработчика не задан, форма ничего не собирает и не хранит: она открывает почтовую программу посетителя с готовым письмом на ggg13@yandex.ru.

Для боевого сайта нужен обработчик, который принимает заявку (FormData) и отправляет письмо. Его адрес задаётся переменной `PUBLIC_FORM_ENDPOINT`, см. `.env.example`. Форма собирает персональные данные, поэтому по ч. 5 ст. 18 152-ФЗ обработчик должен работать на сервере в России — например, PHP-скрипт на российском хостинге, как `api/send-form.php` на текущем сайте. Зарубежные сервисы форм (Formspree, Web3Forms и подобные) не подходят. Перед запуском также нужны политика обработки персональных данных и отдельное согласие на обработку у формы.

## Публикация

`.github/workflows/deploy.yml` собирает сайт и публикует его на GitHub Pages при каждом изменении ветки `main`.

В настройках репозитория (Settings → Secrets and variables → Actions → Variables) задайте:

- `SITE_URL` и `BASE_PATH`: для превью `https://<user>.github.io` и `/<repo>/`, для своего домена `https://xn--24-6kc5aua4d2a.xn--p1ai` и `/`;
- `PUBLIC_NOINDEX=true` для превью, чтобы копия не попала в поиск и не конкурировала с основным доменом;
- `PUBLIC_FORM_ENDPOINT`, когда будет готов обработчик формы.

В Settings → Pages выберите источник GitHub Actions.

Превью: https://pandusss.github.io/himmash-site/ (закрыто от индексации). Боевой сайт лучше разместить у российского хостера на химмаш24.рф: `npm run build` с `SITE_URL=https://xn--24-6kc5aua4d2a.xn--p1ai` и `BASE_PATH=/`, затем загрузить содержимое `dist/`.

## SEO

- У каждой страницы и каждого языка свой адрес, `title`, `description`, `canonical` и `hreflang`.
- `sitemap-index.xml` и `robots.txt` собираются автоматически.
- Разметка schema.org: организация, хлебные крошки, товары (с ценой, где она указана), статьи, частые вопросы.
- После переезда на домен добавьте сайт в Яндекс Вебмастер и Google Search Console и отправьте sitemap. Старые адреса `prod01.html…prod14.html` стоит перенаправить на новые страницы оборудования (соответствие — поле `original` в `src/data/products.ts`).
